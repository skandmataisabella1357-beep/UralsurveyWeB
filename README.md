# Uralsurvey — лёгкая оболочка

Десктопное приложение (Windows и Linux): принимает поток с базовой станции,
разбирает его и показывает станцию точкой на карте.

## Запуск

- Windows: дважды щёлкнуть `start.bat`. Если в папке `runtime/win` лежит среда Electron
  (официальная сборка v44.5.1), больше ничего не нужно. Если её нет, нужен Node.js LTS:
  скрипт сам загрузит Electron при первом запуске.
- Linux: `./start.sh`, нужен Node.js LTS.

Пока приложение запущено из папки проекта, оно следит за файлами: правка интерфейса
(`app/renderer`) перезагружает окно, правка ядра (`core`, `app/main.js`) перезапускает
программу. В этом же режиме оно пишет в папку `samples` файл `status.json` с текущим
состоянием станций и первый мегабайт сырого потока каждой станции — для отладки.

## Что внутри

- `core/` — ядро, от окна не зависит и может работать отдельной службой:
  - `transport.js` — связь: подключение к порту, NTRIP-клиент или ожидание приёмника;
    переподключение и разрыв зависшего соединения;
  - `stream.js` — выделение кадров RTCM 3 и строк NMEA, распознавание сырых форматов;
  - `rtcm3.js` — разбор сообщений: 1005/1006, 1007/1008/1033, MSM1–MSM7, эфемериды GPS;
  - `spp.js` — расчёт координат станции по наблюдениям и эфемеридам GPS,
    когда в потоке нет сообщений 1005/1006;
  - `relay.js` — раздача принятого потока дальше на локальном порту (для приёмников,
    которые отдают данные только одному клиенту);
  - `station.js` — сеанс станции и набор станций;
  - `simulator.js` — имитатор станции для тестов и демо-режима.
- `app/` — окно на Electron: `main.js` (главный процесс), `preload.js` (мост),
  `renderer/` (интерфейс, карта на Leaflet).
- `brand/` — логотип УЦИ: голографический и одноцветный вектор.
- `docs/` — переписка с заказчиком и задача на продолжение работы.
- `test/` — тесты ядра: `npm test`.

## Сборка установщика

`npm run dist:win` на Windows и `npm run dist:linux` на Linux.

## Сторонние компоненты

Leaflet (BSD-2), шрифты Geologica и Martian Mono (SIL OFL) — в `app/renderer/vendor`.
Карта — OpenStreetMap. Записи `GMSD7_20121014.rtcm3` и `testglo.rtcm3` в `test/fixtures`
взяты из тестовых данных RTKLIB (BSD-2), `gmsd-msm4-rtklib.rtcm3` получена из первой
программой str2str, `uscl-mixed.rtcm3` — из pyrtcm (BSD-3).
